# RestApiApp

A Python-based REST API for banking services, built with FastAPI and MongoDB.

## Features
- Customer Management (Create/Read/Update/Delete)
- MongoDB Cloud Atlas integration
- Modular architecture (Controller-Service-Repository pattern)

## Setup
1. Clone the repository and navigate to `RestApiApp`.
2. Create and activate virtual environment:
   ```bash
   python -m venv venv
   source venv/Scripts/activate  # or venv\Scripts\activate on Windows
